Array Connect v0.5.0 增加 macOS 桌面端的管理员授权安装流程。安装后，桌面应用可以普通用户身份连接 VPN。

### macOS

- 应用内置 `array-connect-vpnd`。在 macOS 13 或更新版本首次打开应用时，点击「安装网络服务」，按系统提示完成管理员认证。
- 后台服务由 `launchd` 按需启动，负责 utun、路由和 DNS。VPN 登录、OTP 和钥匙串操作由桌面应用处理。
- 应用构建或 IPC 协议版本与已安装服务不匹配时，会提示更新网络服务。服务安装和更新时校验内置二进制，日常连接无需再次提权。
- 桌面包支持 ad-hoc 签名和可选的 Developer ID 签名及公证。下载后的首次打开遵循 macOS 的安全策略。

### 升级

- 桌面端继续使用已有的连接配置和历史统计。CLI 和桌面端主程序均为 `array-connect`。
- macOS 用户可用新版替换「应用程序」中的旧版，再按提示安装或更新网络服务。

下载区提供 Windows、Linux、macOS 的桌面客户端和 CLI，附带 `SHA256SUMS`。
