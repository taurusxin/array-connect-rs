Array SSL VPN v0.2.0 同时提供 Array Connect 桌面客户端和 `arraysslvpn` 命令行程序，使用同一个版本发布。

### 桌面客户端

- Tauri 2、shadcn Nova、Lucide 和 Zustand；列表管理多个连接配置，首页下拉切换，单次连接一个配置。
- 代理、TLS 后端、CA、公钥固定、路由、DNS、MTU、超时与重连等设置；网关地址可省略 `https://` 和默认 443 端口。
- 密码、代理密码和 BASE32 密钥保存在系统密钥库；支持自动 TOTP，将验证码追加到密码后认证，也支持手动输入验证码。
- TLS 握手成功后再请求密码；实时日志、可配置日志等级、连接时长、流量统计和网速曲线，统计保存在 SQLite。
- 外观与开机自启设置；Windows 通过当前用户的管理员计划任务启动，EXE 嵌入管理员运行清单。
- 关闭窗口时选择最小化到托盘或退出，并可记住选择；所有退出入口在连接尚未结束时确认断开，随后等待网络清理。托盘菜单随连接状态更新。

### 库与命令行

- 修复 Windows 断开时恢复自动 DNS 出现的 IP Helper 参数错误（os error 87），改进错误定位。
- 保留 Rustls 默认后端和显式启用的 OpenSSL 兼容后端；发布包内嵌 OpenSSL，无需目标机器安装 OpenSSL。
- 保留 Array 配置协商边界兼容、密码延后输入、自动重连和脱敏调试日志。

### 下载

- Windows x86_64：桌面 NSIS 安装程序；CLI ZIP（含 Wintun DLL 和许可证）。
- Linux x86_64：桌面 DEB / AppImage；CLI tar.gz，使用 Ubuntu 24.04 构建。
- macOS Apple Silicon / Intel：各架构桌面 DMG 和 CLI tar.gz。
- `SHA256SUMS` 包含全部下载产物的 SHA-256。

Windows 产物尚未配置代码签名；macOS 使用 ad-hoc 签名，未做 Apple notarization。DTLS、完整 IPv6 网络配置及独立提权服务尚未实现；真实网关和网络恢复仍需在目标环境验收。
