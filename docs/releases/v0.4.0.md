Array Connect v0.4.0 为 macOS 恢复系统窗口外观，并统一桌面端和 CLI 的可执行文件名。

### macOS

- 窗口使用系统圆角、原生标题栏和左上角的红黄绿按钮。
- 菜单栏使用独立的单色锁形图标，由系统按菜单栏外观着色。
- 建立 VPN 连接仍需要 root 权限。可在终端通过 `sudo ./array-connect --config ./config.toml` 使用 CLI。

### 可执行文件改名

- 桌面端和 CLI 的可执行文件均为 `array-connect`，Windows 下为 `array-connect.exe`。两者分别打包，请放在不同目录。
- 原先调用 `arraysslvpn` 的脚本和命令需改用 `array-connect`。Rust 库仍以 `arraysslvpn` 为 crate 名。

### 从旧版升级

- Windows 安装器继续按 `Array Connect` 查找旧安装。覆盖安装会清理旧 EXE 并更新快捷方式。若选择先卸载旧版，保留配置时请勿勾选删除应用数据。
- Windows 首次启动新版时，会更新同一安装目录中指向旧 EXE 的已启用自启任务。macOS 和 Linux 如已开启自启，可在升级后关闭再开启一次，刷新启动路径。
- 应用标识仍为 `com.taurusxin.arrayconnect`，新版继续使用现有连接配置和历史统计。

桌面端和 CLI 均提供 Windows、Linux、macOS 构建，下载文件附带 `SHA256SUMS`。
