Array SSL VPN v0.3.0 新增 Array OTP 注册与二维码导出，改进两步验证设置和实时网络活动图表。Array Connect 桌面客户端、Rust 库和 `arraysslvpn` 命令行程序统一使用 0.3.0 版本。

### 桌面客户端

- 两步验证提供「手动填写密钥」和「自动注册」两种方式。填写 BASE32 密钥后自动生成验证码；不设置密钥时，登录及重新认证请求手动输入 6 位验证码，再追加到静态密码后认证。
- 自动注册在本机生成随机密钥，使用配置中的用户名与静态密码提交到 Array 网关。注册前明确提示并要求确认：已有 OTP 注册将被覆盖，旧验证器可能失效。连接和重连不会自动重新注册。
- 候选密钥在提交前保存到系统密钥库。注册结果不确定或本地保存失败时保留候选，重试复用同一密钥，避免丢失网关可能已经启用的密钥。
- 支持生成标准 TOTP 二维码，供其他验证器扫码导入。二维码包含密钥，仅在用户主动操作后临时显示。
- 从网关获取验证码周期和钟差，固定使用 SHA-1、6 位验证码，移除旧算法、位数、自定义周期及「自动认证」配置项。
- 实时网络活动图表支持悬停查看采样时间、下载速度与上传速度，并显示采样点和定位线；提示框限制在图表边界内。
- 调整自动注册区域和偏好设置中「关闭窗口时」等设置行的间距。

### Rust 库与命令行

- 新增 `VpnClient::otp_parameters()`、`VpnClient::enroll_otp()` 和类型化注册结果，支持现有 TLS、代理、证书校验与取消机制，无需创建 TUN 或修改系统网络。
- 增加有长度限制的 HTTP 正文读取，支持 Content-Length、chunked 和连接关闭定界；注册请求拒绝跨源重定向。
- 新增 OTP 协议模拟测试，以及桌面端配置迁移、二维码参数和本地存储失败恢复测试。
- 修复 Windows 发布构建对原生 Perl 的选择，避免误用 MSYS Perl 或将多个解释器路径作为一个程序执行。
- CLI 尚未提供独立 OTP 注册命令或自动生成验证码功能。OTP 自动认证与二维码导出通过桌面客户端提供，注册和参数发现也可通过 Rust 库调用。

### 升级与兼容性

- 首次读取旧配置时迁移 OTP 设置。已启用自动认证、使用 SHA-1 和 6 位验证码的已有密钥继续使用；其他旧设置改为手动验证码认证，连接配置和历史统计保留。
- 更换配置中的网关或用户名后，需要重新导入或注册对应账号的 OTP 密钥。
- 重新注册会覆盖网关中的旧密钥；移除客户端本地密钥不会撤销网关注册。其他 TOTP App 需支持网关提供的周期，并保持设备系统时间正确。
- 两种客户端均内嵌静态 OpenSSL，默认 TLS 后端仍为 Rustls。旧网关可显式选择 OpenSSL 兼容后端，无需另行安装 OpenSSL。
- DTLS、完整 IPv6 网络配置、浏览器 SSO 和独立提权服务尚未实现。不同网关固件及第三方验证器的兼容性需在目标环境验证。

### 下载

- Windows x86_64：桌面 NSIS 安装程序；CLI ZIP，含 Wintun DLL 和许可证。
- Linux x86_64：桌面 DEB / AppImage；CLI tar.gz，使用 Ubuntu 24.04 构建。
- macOS Apple Silicon / Intel：各架构桌面 DMG 和 CLI tar.gz。
- `SHA256SUMS` 包含全部下载产物的 SHA-256。

Windows 产物未配置代码签名；macOS 使用 ad-hoc 签名，未做 Apple notarization。
